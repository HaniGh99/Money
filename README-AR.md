# مدير أموالي — نسخة GitHub Pages (مع Gemini)

تطبيق ويب ثابت (بلا خادم): تنشره على GitHub Pages، وتدخل مفتاح **Gemini** داخل التطبيق فيفعّل **المستشار المالي** و**تحديث الأسعار والأخبار بالبحث على الويب**. حُذفت طرق المزامنة اليدوية (لصق صفحات الموقع وما شابهها).

## 1) النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا (عامًّا) وارفع **كل محتويات هذا المجلد** إلى جذره (Add file ← Upload files). تأكد من وجود المجلد المخفي `.github/workflows`؛ وإن لم يُرفع فأنشئ الملف `.github/workflows/refresh-market.yml` يدويًا (Add file ← Create new file) وانسخ محتواه.
2. Settings ← Pages ← Source: **Deploy from a branch** ← Branch: `main` ← المجلد `/ (root)` ← Save.
3. بعد دقائق يظهر الرابط: `https://اسمك.github.io/اسم-المستودع/`.
4. افتحه من الهاتف وثبّته: أندرويد (Chrome) ← ⋮ ← تثبيت التطبيق. آيفون (Safari) ← مشاركة ← إضافة إلى الشاشة الرئيسية.

## 2) تفعيل الذكاء الاصطناعي
1. أنشئ مفتاحًا من aistudio.google.com/apikey.
2. في التطبيق: «المزيد» ← «🤖 الذكاء الاصطناعي (Gemini)» ← الصق المفتاح ← «حفظ واختبار».
3. بعد نجاح الاختبار يُحدَّث السوق فورًا، ويعمل:
   - **المستشار المالي:** زر «لخّص وضعي» في الصفحة الرئيسية. يرسل ملخصًا لأرقامك إلى Gemini ويحفظ آخر تلخيص.
   - **تحديث الأسعار والأخبار:** زر «⟳ مزامنة»، وتلقائيًا عند فتح التطبيق إن مرّت أكثر من 6 ساعات (يمكن إيقافه). يقرأ Gemini «الليرة اليوم» ومصادر أخرى بالبحث على الويب.
4. حمايات داخلية لحصتك: فاصل 5 دقائق بين التحديثات وحد أقصى 12 تحديثًا يوميًا.
5. اسم النموذج الافتراضي `gemini-2.5-flash`؛ غيّره من الحقل إن تقادم أو تغيّرت أسماء النماذج.

## 3) الأمان والخصوصية (اقرأها)
- المفتاح يُحفظ في **المتصفح فقط** (غير مشفّر) ويُرسل مباشرة إلى Google. لا تستخدم التطبيق على جهاز مشترك، ولا تضع المفتاح في أي ملف داخل المستودع.
- يُنصح بتقييد المفتاح لنطاق موقعك (HTTP referrer) من Google Cloud Console ← APIs & Services ← Credentials.
- المستودع العام يعني أن الشيفرة ظاهرة للجميع؛ أما بياناتك المالية فتبقى على جهازك ولا تُرفع. للنقل بين الأجهزة استخدم «المزيد» ← نسخة احتياطية ← تصدير/استيراد.
- الطبقة المجانية من Gemini قد تُستخدم محتوياتها لتحسين منتجات Google؛ راجع شروطها، وتجنّب إرسال معلومات شخصية حساسة (التلخيص يرسل أرقامًا مجمّعة لا أسماء).
- حدود الطبقة المجانية والبحث فيها تتغير؛ إن ظهرت رسالة حد مؤقت فانتظر.

## 4) تحقق من أخطاء الذكاء الاصطناعي
يرفض التطبيق أي سعر خارج نطاق معقول (يحمي من خلط الليرة القديمة بالجديدة)، أو شراء أكبر من مبيع، أو فارقًا يتجاوز 10%، أو قفزة تزيد على 12%؛ فيبقى السعر السابق وتظهر ملاحظة. تظهر المصادر في بطاقة السوق، ويبقى حقلا سعر الدولار والذهب في أعلى الصفحة متاحين لتصحيح السعر بنفسك. كل ما في الصفحة معلومات عامة وليس نصيحة مالية شخصية.

## 5) (اختياري) تحديث مجدول دون فتح التطبيق
ملف `.github/workflows/refresh-market.yml` يشغّل `scripts/refresh-market.mjs` كل 6 ساعات فيكتب `data/market.json` (ويقرؤه التطبيق كأساس).
1. Settings ← Secrets and variables ← Actions ← New repository secret: الاسم `GEMINI_API_KEY` والقيمة مفتاحك. (السر محفوظ في GitHub ولا يظهر في الشيفرة.)
2. جرّبه يدويًا: Actions ← refresh-market ← Run workflow.
3. ملاحظة: يوقف GitHub الجداول التلقائية بعد 60 يومًا دون نشاط في المستودع العام؛ أعد تشغيلها من تبويب Actions.
- دون السر يتخطّى السكربت التحديث بسلام ولا يفشل.

## 6) استكشاف الأخطاء
| الرسالة | السبب والحل |
|---|---|
| المفتاح غير صالح أو غير مسموح | تأكد من نسخه كاملًا، ومن عدم تقييده بنطاق مختلف |
| بلغتَ حد Gemini المجاني | انتظر قليلًا أو اخفض تكرار التحديث |
| تعذّر الاتصال بـ Gemini | تحقق من الإنترنت ومن اسم النموذج |
| لا تظهر التعديلات بعد رفعها | حدّث الصفحة بقوة (Ctrl+Shift+R)؛ الخدمة تفضّل الشبكة وتُحدّث تلقائيًا |

`node test/run.mjs` يختبر سكربت التحديث بمحاكاة (دون مفاتيح). ملف `index.html` يُولَّد من نسخة الصفحة؛ اطلب إعادة توليده بعد أي تعديل في الميزات.
